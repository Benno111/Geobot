# Support
If you need help with `geobot`, use one of these:

* GitHub issues: `https://github.com/Benno111/geobot/issues`
* Community Discord: `https://discord.gg/w6yvdzVzBd`

# Reporting Bugs
When reporting a bug, include:

* your platform (`Windows`, `Android`, or `iOS`)
* the Geometry Dash version you are using
* the geobot version
* steps to reproduce the issue
* screenshots or videos if they help explain it

# Feature Requests
Feature requests are welcome on the GitHub issue tracker.
